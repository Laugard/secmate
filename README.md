# SecMate Codex Starter Pack

Start med [`00_START_HERE.md`](00_START_HERE.md). Den forklarer præcis, hvordan mappen lægges i et GitHub/Codex-projekt, hvilken første prompt der skal bruges, og hvilke få trin gruppen selv skal udføre.
